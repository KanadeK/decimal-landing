# Security

Version 0.1.x is supported. Run on static local files from a trusted directory.
The CLI makes no network calls and executes no input expressions. Output files
contain the input data and retain its sensitivity. Protect them accordingly.
For sensitive vulnerability reports use
https://github.com/KanadeK/decimal-landing/security/advisories/new
when private reporting is enabled. Otherwise open an issue requesting a private
contact without posting exploit details or private data. Do not attach customer
exports to public issues.
